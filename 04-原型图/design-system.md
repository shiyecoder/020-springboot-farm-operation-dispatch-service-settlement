# 农机作业派单与服务结算管理系统 · 设计系统

> 视觉方向：「数据钢蓝」——面向合作社内部调度的专业业务系统。信息密度高、状态可辨识、无装饰性光效与大插画。
> 后续 build 阶段按本文件 1:1 复刻，颜色/字号/间距不得自行改动。

## 1. 色彩

| 语义 | 变量 | 色值 | 用途 |
|---|---|---|---|
| 主色 | `--c-primary` | `#19324A` | 顶部栏、主按钮、当前菜单、关键数字 |
| 主色-深 | `--c-primary-700` | `#122536` | 主按钮 hover、表头文字 |
| 辅助色 | `--c-secondary` | `#356A7A` | 次级按钮、筛选选中态、图表系列 2 |
| 强调色 | `--c-accent` | `#456C7E` | 链接、信息提示、图表系列 3 |
| 页面背景 | `--c-bg` | `#F4F6F8` | 主内容区 |
| 容器 | `--c-surface` | `#FFFFFF` | 卡片、表格、表单容器 |
| 分割线 | `--c-line` | `#E3E8EC` | 表格行线、卡片边框 |
| 正文 | `--c-text` | `#1F2A33` | 主要文字 |
| 次要文字 | `--c-text-2` | `#5C6B78` | 标签、说明 |
| 弱文字 | `--c-text-3` | `#8B99A5` | 占位、禁用 |
| 成功 | `--c-success` | `#2B7955` | 已完成、已通过、正常 |
| 危险 | `--c-danger` | `#B02A37` | 驳回、超时、异常、删除，仅小面积 |

图表系列色（同一含义跨页一致）：`#19324A` / `#356A7A` / `#456C7E` / `#7C93A0` / `#A9BAC4` / `#C9D4DA`。

**状态永不只靠颜色**：所有状态标签必须带中文文字，关键状态额外带图标。

## 2. 字体与字阶

- 字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`
- 数字：`font-variant-numeric: tabular-nums`，金额/面积/工时/油耗列全部启用，保证纵向对齐

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| H1 页面标题 | 20/28 | 600 | 内容区标题 |
| H2 区块标题 | 16/24 | 600 | 卡片标题、抽屉标题 |
| 正文 | 14/22 | 400 | 表格、表单、段落 |
| 辅助 | 13/20 | 400 | 表头、说明文字 |
| 微 | 12/18 | 400 | 标签、时间戳 |
| 指标数字 | 26/32 | 600 | KPI 卡数值 |

## 3. 间距与栅格

- 基准 4px；常用 8 / 12 / 16 / 24 / 32
- 内容区外边距 24px，卡片内边距 16–20px，卡片间距 16px
- 外壳：侧边栏 220px（折叠 64px）+ 顶部栏 56px + 自适应内容区
- 表单：标签 100–120px，单列输入宽 360–520px，搜索下拉 180–240px

## 4. 圆角与阴影

- 圆角：卡片 8px、按钮/输入 6px、标签 4px、头像 50%
- 阴影**只用于浮层**：抽屉/弹窗 `0 8px 24px rgba(25,50,74,.16)`；卡片无阴影，靠 1px 边框区分层次

## 5. 核心组件规范

### 按钮
| 类型 | 背景 | 文字 | 边框 | 高度 |
|---|---|---|---|---|
| 主按钮 | `#19324A` | `#fff` | 无 | 34px |
| 次按钮 | `#fff` | `#19324A` | `1px #C9D4DA` | 34px |
| 文字按钮 | 透明 | `#456C7E` | 无 | 32px |
| 危险按钮 | `#fff` | `#B02A37` | `1px #B02A37` | 34px |

按钮圆角 6px，内边距 0 16px，字号 14px。行内操作只用文字按钮，每行最多「查看 + 2 个高频操作」，其余进「更多」。

### 输入
高 34px，边框 `#C9D4DA`，聚焦边框 `#356A7A` + 2px 外发光 `rgba(53,106,122,.12)`；错误态边框 `#B02A37` 并在下方 12px 红字说明。

### 表格
表头高 44px，底色 `#EDF2F5`，字号 13px，颜色 `#122536`，字重 600；行高 48px；斑马纹 `#FAFBFC`；`th` 不写死宽度（`min-width` + `white-space:nowrap`），编号/状态/日期/操作列单行。分页默认 10 条，可切 20/50。

### 标签（状态）
高 22px，圆角 4px，字号 12px，内边距 0 8px。语义映射：
- 待报价/待确认/待排程/待作业 → 中性 `#EDF2F5` / `#456C7E`
- 作业中 → 辅助 `#E4EDF0` / `#356A7A`
- 待验收 → 警示 `#FBF1DF` / `#9A6412`
- 已完成 → 成功 `#E4F0EA` / `#2B7955`
- 异常/驳回/超时 → 危险 `#F8E6E8` / `#B02A37`

### 卡片
白底、1px `#E3E8EC`、圆角 8px、内边距 16px；卡片标题 16px/600，右侧可放筛选或「更多」。

### 抽屉 / 弹窗
右侧抽屉宽 560px（复杂表单 720px），顶部标题栏 56px，底部操作条固定；遮罩 `rgba(25,50,74,.35)`。审批类抽屉内必须同时展示单据摘要。

### 分页
右对齐，按钮 32×32，当前页 `#19324A` 底白字，其余白底描边。

## 6. 角色视觉区分

| 角色 | 外壳 | 强调 |
|---|---|---|
| 调度员 / 机务管理员 / 财务人员 / 管理员 | 后台：左侧深色菜单（`#19324A`）+ 56px 顶栏 | 数据钢蓝，表格密集型 |
| 农户客户 | 门户：顶部导航 + 内容流，卡片式需求列表 | 白底大留白，主按钮钢蓝 |
| 农机手 | 移动优先：单列卡片 + 底部固定操作区 | 大点击区（≥44px），现场录入入口前置 |

## 7. 响应式

- ≥1440：三栏/双栏正常
- <1200：KPI 由 6 列降 3 列，图表 2 列
- <768：侧边栏转抽屉，筛选折叠为底部面板，表格转信息卡片（仅编号/状态/时间/负责人），点击卡片进详情；底部固定操作区不得遮挡分页

## 8. 动效

- 页面切换不做转场；抽屉 200ms 从右滑入
- 表格加载 >300ms 显示骨架行，禁止整页白屏
- 图表不做出场动画（避免演示视频抖动），仅 hover 高亮
